# Blog

Posts live here, one Markdown file each, named `YYYY-MM-DD-slug.md`, with `title`, `date`, `product`, and `draft` in front matter. A post stays `draft: true` until it is ready.

The site in `apps/site` shows them; until it has a build step, each post page there is written by hand from its file. The layout is in [`design/layouts/blog-post.md`](../../design/layouts/blog-post.md).
