# Design

`brand/` says what Villain feels like. This folder turns that into numbers and reference layouts.

Caster is AppKit. Forge, Layer, and the site are web. Each one builds its screens in its own toolkit, from the same tokens and the same layouts.

| | |
| --- | --- |
| [`tokens/`](tokens) | The numbers: color, type, space |
| [`layouts/`](layouts) | Reference layouts: a window, a post, a social card |
