Confidence

The pill beside each language (e.g. 95%) is the model's own confidence in its translation, not an independent quality check. Its colour compares the score with the pair's review threshold (Settings → Language pairs).

  • ≥ thr At or above the review threshold: the model is confident.
  • 50–thr Below the threshold but plausible: flagged for review.
  • < 50% The model thinks this is likely wrong: review it.
  • human Edited or reviewed by a person: no automatic score.

Manage namespaces

Rename rewrites every key across every language. Delete wipes the namespace and removes its JSON files on disk. Both are immediate; there is no undo.
