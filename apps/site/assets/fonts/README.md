# Fonts

Unmodified variable TrueType files from the official Google Fonts repository, downloaded 2026-10-16. The full character sets are retained. `fonts.css` exposes the weights used by the brand with `font-display: swap`.

Each family’s SIL Open Font License is included alongside the files. Keep those licenses with any deployment.
