# Shared design snapshot

These color/type/shape tokens and licensed font files are copied from the vault's
`design/tokens/` and `apps/site/assets/fonts/`. Run `bun run design:sync` from
`apps/forge` to refresh them. The same command copies `brand/mark/forge.svg`
to the web icon. Do not edit these copies by hand.

The bundle keeps Docker and standalone Forge builds self-contained. Brand
guidance lives in the vault's `brand/`; UI principles and component rules live
in `design/`.
