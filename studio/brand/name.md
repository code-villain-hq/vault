# Name

The studio is **Code Villain**. Write it as two words, with both initials capitalised. The website is **https://www.codevillain.eu/**; the domain is written without a space.

The products are **Forge**, **Layer**, **Caster**, and **Glyph**. Use those names in app titles, menus, packaging, and writing. The editor and terminal theme is called **Code Villain** ("Code Villain Night", "Code Villain Day"); Nightshade stays the palette's name. When the maker matters, write “Layer by Code Villain” or “Code Villain builds Forge.”

Code Villain replaces the studio name Villain Studios. The Nightshade palette, type pairing, villain voice, and gothic strike mark carry forward; the mark now reads CV, so the compact form says Code Villain too. The full wordmark reads “Code Villain” on one line.

Existing repository addresses, package names, bundle identifiers, keychain services, data folders, signing identities, and integration keys keep their technical names. Changing these requires a separate migration; a display-name change must preserve access to existing work and settings.
