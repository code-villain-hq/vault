# Site

The Code Villain website at **https://www.codevillain.eu/**: the homepage, and the blog, built into `blog/`. Shared styles are in [`site.css`](site.css).

The blog is generated from [`studio/content/blog`](../../../studio/content/blog). `python3 build.py` renders each post's Markdown into `blog/` through [`templates/`](templates) with [`blog.py`](blog.py): a page per post and the index, newest first. `blog/` is build output, not in git; edit the Markdown or the templates. The preview shows drafts with a pill; `dist/` leaves them out.

The Markdown is the plain subset the posts need: `##` and `###` headings, paragraphs, lists, quotes, fenced code, links, images, inline code, strong and emphasis. Straight quotes become curly. A paragraph of images alone is a figure, the image title (`![alt](path "caption")`) its caption; two images in one paragraph share a panel. Image paths are relative to the post. CSS and SVG/HTML code takes the code palette; other languages stay plain. Reading time counts prose at 200 words a minute.

It reads colour, type, and shape from [`studio/design/tokens`](../../../studio/design/tokens) by relative path, so run `python3 build.py` once for the blog, then open it through the vault's preview server (`vault-static` in `.claude/launch.json`, then `/apps/site/`), not from disk. `python3 build.py` copies the public assets and rewrites their references for deployment at the domain root.

The homepage uses the outlined [`logo-home.svg`](../../../studio/brand/mark/logo-home.svg) variant through an external SVG reference. Its extended strike and cropped lettering are defined in [`studio/brand/mark/README.md`](../../../studio/brand/mark/README.md).

Fonts are self-hosted in [`assets/fonts/`](assets/fonts/), including the reading italic and each family’s SIL license. Every page loads `assets/fonts/fonts.css`; the brand reference page reuses it. Ship this folder with the site.

The homepage keeps the extended-strike logo above a product showcase. Forge leads; Layer and Caster sit beneath it, stacking below 800px, Glyph follows at full width, and Raven and the Code Villain theme close the showcase as a pair that stacks the same way. Each card shows the product's name and line, one capture, one sentence, and “More on …” to its page. A closing section, “Built one way.”, names what Forge, Glyph and Raven share: offline first, the company's sign-in, a desktop app with no server, one public repository. Styles specific to the homepage live in [`home.css`](home.css).

Every page's header has a Products menu (a `<details>` disclosure listing each product with its icon and line; [`menu.js`](menu.js) closes it on Escape or a click outside) and The log. The homepage's copy of the menu must match `products.menu(0)`; `test_products.py` checks it.

Each product has a page at `/<product>/`, generated by [`products.py`](products.py) through [`templates/product.html`](templates/product.html) from its file in [`studio/content/products`](../../../studio/content/products): a hero (icon, name in the display face, lead, where it runs, links) and a capture, three features with a capture each, alternating sides, then a quiet row of points with a bold lead word. Styles live in [`product.css`](product.css). Edit the TOML, not the generated pages. The words claim only what is built: Forge AI and Raven's Product level are left out.

Captures live in [`assets/captures/`](assets/captures/), taken at 2× in Nightshade night; `products.size()` halves their pixels, and `build.py` ships only the captures a page shows. None shows live user data, and each caption says where its data comes from:

- Forge: `bun run dev` for Acme Inc with a made-up shop (team Shop, services Checkout, Catalog and Accounts, their specs, eleven issues), and a Claude Code agent working on SHOP-1 through Forge's MCP server.
- Layer: its mock harness (`/mock.html?view=work&task=t-login` and the other views), the harness's example data.
- Caster: its own window alone, on the card's ground rather than a wallpaper.
- Glyph: `bun run dev` with `bun run seed`, the made-up strings in `code/apps/glyph/demo`.
- Raven: `bun run dev` for Acme Inc, with a made-up Acme Shop sending a day of traces and logs over OTLP.
- The theme: its specimen, clipped to the editor parts.

Product icons come from each app's existing SVG asset. The theme is called Code Villain, so it takes the studio mark, [`mark.svg`](../../../studio/brand/mark/mark.svg). The pages follow “show less”, “tone, not lines”, and “display for headings” from the shared principles.

Page titles, descriptions, canonical links, and Open Graph metadata use Code Villain and the `www.codevillain.eu` origin. Serve the homepage at `/` and the blog at `/blog/`; keep the existing post URL when deploying. DNS, TLS, and redirects for the bare domain are hosting configuration.

## Build and host

Run `python3 build.py` from this folder. The `dist/` folder contains only the public HTML, styles, fonts and licenses, outlined marks, product icons, blog illustrations, and `.htaccess`. The builder checks every local HTML and CSS dependency. Vault source, internal design documents, app code, and brand drafts stay out of the upload. The `/design/` URL space returns 404.

`uberspace.htaccess` becomes the site's `.htaccess`. It sends the bare domain to `https://www.codevillain.eu/`, answers `/design/` with 404, and redirects old Forgejo paths that match no site file to `https://git.codevillain.eu/`, keeping Git HTTP request methods.

Where the site is hosted and how a build is deployed lives in the private `infra` repository, not here. Never upload a vault checkout into a public document root.
