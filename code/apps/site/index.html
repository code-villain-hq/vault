Built one way.

  • Offline first. Forge, Glyph and Raven keep a copy of the workspace on every client. It opens at once and catches up when the network returns.
  • Your company’s sign-in. A server runs for one company. People sign in with its account over OpenID Connect and arrive over SCIM. No passwords, no invites.
  • No server needed. The desktop apps start their own Postgres and server for the workspaces on that Mac.
  • In the open. Every tool lives in one public repository.
