The workspace's own topic

Every workspace starts with one topic already in it: Almanac, which knows the workspace and starts topics for you. And Claude on this Mac, through Claude Code over ACP as Layer's conversations run, so there's no key to paste. Night and day, with the Nightshade tokens. The content is made up.

1A new workspace opens on its own topic

You make Home. It isn't empty: Almanac is already there, above Calendar, and Home opens on it. It has nothing to keep yet, so it asks what you want to keep track of.

  • My choice: it's called Almanac, sits out of the groups, and can't be deleted. You can rename it.
  • My choice: its first questions are about what you want to keep, not about Almanac.
  • My choice: New topic, or C, still opens the dialog, for when you already know the name.

4Claude on this Mac, with no key

Almanac starts Claude Code over ACP, as Layer does for a conversation, and Claude answers as you're signed in to Claude Code. Settings → Claude says so, and what to do when it can't.

  • My choice: Almanac gives Claude its own prompt and only Almanac's tools: keep a point, ask you, offer a reminder, start or change a topic. Not your files, your shell, or your Claude Code settings and CLAUDE.md.
  • My choice: Almanac never signs in for it. Without the ACP adapter, the page gives the one command to install it; signed out, it says to run claude in Terminal.
  • Open: web search. Claude Code can search the web; on, an answer says what it searched and links its sources.
  • Open: the key stays only for a company server later, where there's no Claude Code.
