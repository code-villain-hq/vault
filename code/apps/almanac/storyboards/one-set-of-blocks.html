One set of blocks

Notion's few blocks, and you never arrange them. You say something; Claude puts it in a block, or as a row in a collection when it has fields. A collection's fields pick its picture, by the same rules on every page: Lisa's weighings make a line because they're days and numbers, not because Katzen has a design.

1Seven blocks, eight pictures

  • Blocks: Heading, Text, Bullets, Checklist, Toggle, Callout, Collection. Every page on every topic is made of these.
  • A collection is rows with fields, and each row is a page of its own, made of the same blocks. Long text goes there or in a Toggle, never on the face.
  • Its picture comes from its fields, first match wins. View as offers the others its fields allow. Nobody designs a page, not you and not Claude.
  • A checklist item can repeat and ring: "Lisa kämmen" every day is a tick on the page, and Calendar shows it with the rest.

5You say it, Claude files it

  • "Lisa hat heute 3,4 kg gewogen": Claude adds a row to Gewicht. The line on the page gains a point, and the answer shows the line too.
  • The first weight starts Gewicht. One row shows as the number; the line starts at two.
  • Claude edits through tools only: add or change a row, tick, add or move a block, start a collection. It never picks a colour, width or picture. When you ask for another picture, it switches among those the fields allow.
  • Every change says where it went, with Undo.

6What changes

  • Points, sections and facets become rows, fields and blocks. Today's fifteen views become seven blocks and eight pictures.
  • The plan's step 3 (what Claude is told) becomes the tool list in 5. Step 4 (re-import) moves each topic into blocks, the way 2 to 4 show.
  • You can still click: tick, edit a cell, drag a card. You never have to.
  • Made up: Wohnung reparieren, Lisa's weighings and Kuba's lines. The rest is your pages.
  • Open: can you add a block by hand (a "/" menu, as in Notion), or only by saying it?
