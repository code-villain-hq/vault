Adding blocks by hand

Today a talk makes every block. By hand you can only add a row to a collection (+ New) and a picture at the end of a page. Proposed: you add any block of the set yourself, and write what it starts with in place. A talk still keeps things the same way; your blocks are ordinary blocks it reads and tidies like its own.

1 Add a block, where Add a picture is

  • One button at the end of the page, in Add a picture's place: Add a block. A picture is one of the kinds, and a photo dropped on the button still makes one.
  • The set's kinds, by the names Settings → Blocks uses. A collection starts as a list, a checklist or a table, because its fields pick its picture; View as and Fields change it after.
  • On a row's own page the same button adds the block to that page.

2 Between blocks: Add below, in the block's ⋯

  • No + in every gap. The ⋯ each block already has (Move up, Width, Rename, Remove) gets Add below, with the same kinds. Nothing new shows until you ask (principle 1, show less), and it works for blocks side by side at half width, where a gap has no clear "between".
  • ⌘K offers the same on a topic's page: Add a heading, Add a paragraph, Add a checklist… at the end.

3 What it starts with is written in place

  • A heading, a paragraph or a callout opens with a line to write in, where it will read. Enter keeps it; in a paragraph Enter starts the next passage and ⇧Enter breaks the line. Esc, or leaving it empty, takes the block off again.
  • A list, a checklist or a table opens on its title, then its first row (the + New that's there today). A table starts with one field, Notes.
  • A click on any passage, heading or callout writes in it, as a click on a row's value does today. Without it a block you added could never be corrected.
  • What you write is "You wrote" as its source, so the page and a talk tell it apart from what Claude found.

4 A collection's fields, by hand

  • Fields… in a collection's ⋯, beside View as: each field's name and kind, in order. Add a field, drag one to move it, ✕ to remove it; a choice and a status name their words, a number its unit.
  • The kinds are the ones a talk uses: Text, Number, Day, Choice, Status, Check, Photo, Link; eight at most, as now.
  • Removing a field rows fill is the one thing that asks first: "Katzensicher is filled in 3 rows. This can't be undone."
