A better layout

The import put all 47 things Katzen knows about Lisa on one card, because Grok's notes had no sections. Today a talk can only add points to the page; moving blocks is up to you, one at a time, in the ⋯ menu. Here you ask the topic's talk to lay the page out better, and it does it while you watch. Undo puts everything back.

1You ask, the page changes

  • Only when you ask, in the topic's own talk. Almanac never re-lays out a page on its own.
  • What it may do: add, rename, reorder and remove blocks, change a block's kind, and move points between blocks and themes.
  • It may reword a point to fit its new place, a card line into a chip, and keeps every fact in it. "What moved" says which it reworded.
  • It never drops a point and never changes where one came from. A block it empties goes.
  • It changes the page at once. The page beside the talk is the preview, so there is no proposal to read first; the Changes box says what moved, and Undo puts every block and point back.
  • My choice: one Changes box for the whole layout, not one per move, so one Undo undoes it. The cards show four points each, as in a section opens.

2A timeline from what's kept

  • The same ask makes a new kind of block. "Mach eine Zeitleiste daraus" reads Geschichte's sections for what happened when, and keeps each as an event with its date and its section, on a new Timeline at the top.
  • The sections stay as they are. An event is a new point beside the passage it came from, so Undo removes the events and the block, and nothing else.
  • Later talks keep events too, once the page has a timeline: what happened goes into its section and onto the timeline.
