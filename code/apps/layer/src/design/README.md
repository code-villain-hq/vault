# Shared design snapshot

Copied from the vault's `studio/design/tokens/` and `code/apps/site/assets/fonts/` by
`bun run design:sync`. Do not edit these copies by hand: change the vault's
sources, then sync. `bun run check` fails while the copy differs.

`theme.css` maps these onto the app: Nightshade is the default theme in
night and day, and the other themes fill the same colour names.
